# Original Figaro documentation archive

These are unchanged historical documents, not the maintained Scala 3 user guides.
Their notices, original authorship and publication context are retained. Old instructions
and third-party contact details are archival, not current support/dependency directions.

| File | Pages | Why retained |
| --- | ---: | --- |
| [Quick Start Guide](<original-doc/Figaro Quick Start Guide.pdf>) | 22 | Figaro 5 onboarding, Constant/Select and Burglary teaching sequence |
| [Release Notes](<original-doc/Figaro Release Notes.pdf>) | 5 | Original Figaro 5 feature and release history; do not rewrite history as Scala 3 |
| [Tutorial, original doc edition](<original-doc/Figaro Tutorial.pdf>) | 95 | Detailed modeling and algorithm-extension explanations |
| [Tutorial, LaTeX edition](tutorial-latex/FigaroTutorial.pdf) | 109 | Different, longer edition including structured factored inference and experimental features |

The tutorial PDFs are **not duplicates**. The original LaTeX chapter sources also remain
under [FigaroLaTeX](../../FigaroLaTeX/README.md), with a new modernization preface.
The preface is not present in these historical PDFs. Hash preservation is checked by
`tools/docs/test_legacy_documentation.py`.

Start with [current documentation](../README.md). Follow the [topic migration map](../../docs/DOCUMENTATION_MIGRATION.md)
to use historical depth alongside current contracts. Neither archived code snippets nor
all advanced workflows have been revalidated simply because they are preserved here.
